# 04-fitness

Счётчики упражнений по захвату движения. Работают в браузере телефона,
видео никуда не уходит — модель считает позу прямо на устройстве.

Сейчас готово: **приседания**.
Дальше: отжимания, скручивания.

## Как запустить

GitHub Pages: Settings → Pages → Source: Deploy from a branch → `main` / root.
Адрес будет `https://p4rzifalus.github.io/04-fitness/`.

Локально по `file://` камера не откроется — нужен `localhost` или https:

```
python3 -m http.server 8000
```

## Как это работает

```
кадр → поза (33 точки) → угол в суставе → сглаживание → машина состояний → повтор
```

Четыре фазы в интерфейсе:

1. **Рамка.** Проверяется видимость точек, дистанция, попадание в рамку и ракурс.
   Показывается одна претензия за раз — самая важная из непройденных.
2. **Подтверждение.** Верная поза должна продержаться две секунды, иначе
   она «подтвердится», когда человек просто проходит мимо камеры.
3. **Калибровка.** Шесть секунд на один медленный присед. Пороги берутся из
   фактической амплитуды человека, а не из зашитых градусов — иначе одни
   и те же числа не работают у людей с разной подвижностью.
4. **Счёт.** Гистерезис: вниз при 25% амплитуды, вверх при 75%. Зазор между
   порогами — защита от дрожания на границе.

## Структура

```
index.html          разметка и стили
src/exercises.js    дескрипторы упражнений — единственное место про конкретное движение
src/core.js         поза, геометрия, проверка постановки, машина состояний, запись
src/ui.js           рамка, скелет, шкала глубины, звук, речь
src/debug.js        панель порогов
src/app.js          оркестровка фаз
lab/                прогон записанных подходов без камеры
lab/recordings/     эталонные записи с известным числом повторов
```

## Как добавить упражнение

Дописать объект в `EXERCISES` в `src/exercises.js`: тройка точек для угла,
список точек для проверки видимости, пороги. Ядро про упражнения не знает.

Для отжиманий понадобится ещё валидатор позы — угол плечо–таз–щиколотка
должен держаться в районе 160–180°, иначе прогиб в пояснице засчитается
за повтор. Это единственное, что придётся дописать в ядро.

## Рабочий цикл

Основная работа тут — подбор чисел, а не написание кода. Поэтому:

- **Пороги крутятся кнопкой «Пороги»**, значения живут в `localStorage`.
  Нашёл рабочие — перенеси руками в `exercises.js` и закоммить.
  Через коммит → пуш → ожидание Pages подбирать невыносимо.
- **Подходы записываются** кнопкой «Скачать подход» и прогоняются в `lab/`
  без камеры. Отладка счётчика идёт за столом, а не в приседе.
- **Рабочие состояния помечаются тегом:** `git tag v0.1-squat && git push --tags`.
  Очень легко «улучшить» пороги и потерять то, что работало.

## Что ещё не проверено на живом человеке

- `sideRatioMax = 0.22` взят из типичных пропорций, а не из замера
- `enterUp = 0.75` может промахиваться к концу подхода, когда от усталости
  перестаёшь полностью выпрямляться — тогда опустить до 0.65
- модель `lite`; если точки колена дрожат, поменять на `full` в `src/core.js`
  (станет точнее, но на телефоне может просесть fps)
